# Location map

Open **Monitoring → Location** to see on a map where playback comes from, based
on the IP address of each stream. Only administrators see this map.

## Live and recent playback

Switch between recent playback and live playback only. Filter by server or
country, select a stream where available, and turn on the heatmap to see where
activity concentrates. The map follows the sessions VODUM collects; it does not
track devices continuously.

## A past period

Choose **1 day**, **7 days** or **30 days**, then use the timeline to look at a
moment in that period; the play button moves through time. The live switch is
off while a period is selected; return to the current view to get live updates back.

## Reading a location

A location from an IP address is approximate. VPNs, proxies, mobile networks and
shared connections can put several people at the same place, or move one person
between places. Local network addresses have no location. A missing location
does not mean the user is inactive.

Use the map together with the session details and your [stream policies](policies.md),
never as the only reason to block a user.
