# Logs

The **Logs** page lists what VODUM did and the errors it met.

- Filter by level (info, warning, error…) or search for a word, a task or a server.
- Counters per level cover the whole kept history, not only the visible page.
- Multi-line errors are shown in full in their event.
- **Download logs** exports an anonymized text file to attach to a support request.

The dashboard only shows the latest events. For an action that seems stuck, also
check the task in [Tasks](tasks.md) or the message in the delivery history. For
slow pages, see [Performance](performance.md).

!!! warning "Before sharing logs"
    Anonymization removes most personal data, but read the file before posting
    it publicly. Never share backups or authentication details.
